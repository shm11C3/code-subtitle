CODE SUBTITLE / LOGO EXPLORATION

コードのそばに、理解のひとこと。

3つの方向を、同じ背景・同じ表示サイズで比較。採用案は A（白い括弧＋緑の2本線、矢印なし）です。

A — Inline Caption（採用）

コード括弧と短い字幕。機能が最も直接的に伝わり、コンパクトに使える案。

B — Caption Bubble

吹き出しにコードと字幕をまとめた親しみやすい案。チャットの印象もやや強め。

C — Reading Anchor

コードから理解へ向かう動きを表現。個性はある一方、小さい表示では要素が多め。

画像生成ツールによる原案です。A を採用し、発光・縁のノイズを整えた公開用アイコンを作成しました。
